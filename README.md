# Beibit Akysh · CV landing

Live: https://akyshb.github.io/akyshcv/ (`?lang=ru` or `?lang=en` skips the language picker).

- `index.html` is built from the Claude artifact source; edit there, then rebuild and push.
- `media/` holds photos and the RU/EN PDF résumés.
- `tilda-embed.html` is the code for a Tilda T123 block. It frames this site full-screen, so every push shows up on Tilda without republishing.
- `embed.js` runs on the Tilda page: on iOS it passes a tap on the status bar to the framed CV, which scrolls to the top.
